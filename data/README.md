# Data Folder

## raw/
Place the two files provided by the module here, unmodified:
- `smartcare_ai_dataset_1000.csv`
- `smartcare_ai_dataset_data_dictionary.csv`

Never edit files in `raw/` directly — treat it as read-only source data.

## processed/
Auto-generated by `src/preprocessing.py` (Chanuu, Task 03). Do not hand-edit;
regenerate by re-running the preprocessing pipeline:

```bash
python -m src.preprocessing
```

Files produced:
- `processed_full.csv` — full cleaned + feature-engineered dataset
- `train.csv` / `test.csv` — stratified train/test split used by all downstream tasks
